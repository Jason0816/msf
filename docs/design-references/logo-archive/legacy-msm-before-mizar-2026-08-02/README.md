# Legacy MSM Logo Archive

This directory preserves the complete logo set that was in active use immediately before the Mizar blue-ribbon logo rollout on 2026-08-02.

## Contents

- `files/logo.png`: root/fnOS package logo.
- `files/web/public/logo/`: public web logo and favicon sources.
- `files/web/src/app/favicon.ico`: application favicon.
- `files/internal/server/web/dist/logo/`: previously built web logo files.
- `files/logo_motion/`: complete legacy animated-logo source and rendered outputs.
- `files/web/public/logo-motion/`: legacy login animation layer assets.
- `files/packaging/unraid/`: Unraid CA and plugin icons.
- `files/macos/MSFMenuBar/Resources/`: macOS master and full AppIcon set.
- `SHA256SUMS`: integrity hashes for every archived file.

The paths beneath `files/` mirror their original repository locations. To restore one asset, copy it from `files/<original-path>` back to `<original-path>`.

The sibling archive `legacy-msm-before-mizar-2026-08-02.tar.gz` contains this whole directory for portable backup.
Its checksum is stored in `legacy-msm-before-mizar-2026-08-02.tar.gz.sha256`.
