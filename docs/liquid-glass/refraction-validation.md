# Liquid Glass 折射验证记录

验证日期：2026-08-02  
验证环境：本地 Vite 开发服务器、Chromium、固定 `1440×900` 视口  
实验路由：`/__liquid-glass-lab`

## 结论

SVG `feDisplacementMap` 暂不进入生产组件。正式 Header、Sidebar、MobileNav 和数据卡继续使用稳定的 CSS Liquid Glass。

原因：更新后的位移图已将中央区域设为中性 `#808080`，仅在四周 12.5% 边缘带写入 X/Y 位移，但 Scale 0/24/48 截图比较中，中心 ROI 的平均绝对像素差仍高于边缘 ROI。该结果不满足“边缘形变明显、中心阅读区稳定”的生产门禁。

## 生产决策

- 不在正式表面设置 `.gary-glass--refractive`。
- 保留开发实验页和 filter defs，便于浏览器实现变化后复测。
- 大卡片始终使用 CSS blur、K-only fill、左上非对称边缘和接触阴影。
- 若未来复测，必须先达到 `edge MAE > center MAE`，再进行盲测和性能验证。
